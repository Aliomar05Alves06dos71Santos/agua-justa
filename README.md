Bem-vindo ao Projeto Água Justa

O Água Justa é um projeto brasileiro que busca ajudar os consumidores a compreender melhor suas contas de água e esgoto por meio de análises simples, cálculos e informações claras.

Nosso objetivo é promover transparência, educação e acesso à informação, permitindo que qualquer pessoa identifique possíveis inconsistências em sua fatura e entenda melhor os serviços de saneamento.

Funcionalidades

- 💧 Análise simplificada da conta de água.
- 📊 Cálculo do consumo.
- 💰 Estimativa do valor da conta.
- 🚿 Análise da cobrança de esgoto.
- ⚖️ Identificação de possíveis irregularidades.
- 📱 Aplicativo instalável (PWA).
- 🔄 Atualizações contínuas.

Tecnologias

- HTML
- JavaScript
- Manifest (PWA)
- Service Worker
- GitHub Pages

Objetivo

Contribuir para que os consumidores tenham mais conhecimento sobre suas contas de água, incentivando o uso consciente da água e fortalecendo o acesso à informação.

Status do Projeto

🚧 Em desenvolvimento contínuo.

Novas funcionalidades estão sendo planejadas para tornar o aplicativo cada vez mais completo e útil para a população.
